# 爆炸、触控布局与 Terraria Boss 修订

更新：2026-11-17。源码和验证工作；本轮未出 EXE 分发包或 APK，未改正式启动器和用户存档。

## 爆炸崩溃

用户确认发生在快速测试包之前的版本；尚不能据此确定完整构建号，也没有确认当时是否存在魅惑单位。

生产 `NativeFrameRecorder` 原来在单帧超过 12,000 条绘制命令时抛出 `Native draw command limit exceeded`。900 个辣椒僵尸集中爆炸可稳定触发，修复前证据在 `limit-900-v2/results.json`。现在到上限后优先丢弃后续爆炸、粒子的显示命令，并允许随后绘制的单位替换已有临时特效；不再因为绘制超限终止对局。减少的是显示，不删除战斗实体、不减少爆炸伤害、不采样额外战斗随机数。`transient` 和丢弃计数不写入战斗/网络数据。

- `limit-900-fixed/results.json`：900 个辣椒僵尸、13,500 个特效实体，绘制命令保持 12,000，峰值丢弃 2,403 个显示请求，继续推进通过。
- `rendered-fixed-128/results.json`：小丑、辣椒、毁灭菇及混合四组，各包含普通与交错魅惑两种配置，八组通过。每组推进 180 个房间步并真实绘制 45 帧。该数量下未触发显示丢弃。
- 魅惑小丑/混合组会按现有规则提前消灭其他爆炸源，不能把“放入 128 单位”误写成“128 次爆炸都实际执行”。每组实际实体峰值在 JSON 中。
- Windows 进程内存包含冷启动参照和跨场景缓存；不是手机 RSS，也不是受控低内存设备测试。

**仍未证明：**用户手机/低配 PC 的少量同时爆炸必然由这个上限引起。当前未连接手机，未拿到该旧版崩溃栈；此次确定修复了已复现的异常退出路径，不能宣称所有旧版闪退已消失。

最早的 `baseline-32`、`baseline-128`、`cross-faction-128` 缺少地图参数，只能证明模拟推进，不能作为特效绘制验收。`rendered-32` 初次读取地图格式失败。失败和无效证据保留，真正绘制证据从 `rendered-32-v2` 起算。

## 触控布局

拥有者为 `tools/pvp72_sources/touch.py`，由 `tools/pvp744_controls_hooks.py --generate` 生成生产 UI。CMake 与 Android 构建增加 `--check` 门禁。

- 在自定义布局中轻点按键打开设置，拖动仍调整位置；普通按键可在方形、圆形间切换。
- 左右移动可选双按键、圆盘摇杆或关闭。摇杆上拉触发跳跃；角度是以正上方为中心的总角度，20°–160°，默认 60°。
- 自动/左/右可合并为“左－自动－右”滑动条，按住滑动可以连续更换朝向；自动继续使用当前戴夫面朝方向。
- 陀螺仪默认关闭，支持开关、握持角度校准和倾斜阈值。触摸移动优先；失焦、离开对局、观战等场景释放移动输入并关闭传感器。无陀螺仪时显示不可用，不模拟硬件支持。
- 设置落盘，旧布局继续可读；多个手指、跳跃边缘触发、拖动锚点与释放不粘键已通过生成后 C++ 的实际输入路径检查。

传感器使用 SDL 加速度计和陀螺仪融合，仅把结果转换为已有移动输入。补测发现的反复开关 SDL 子系统引用泄漏已修复，覆盖独占及共享初始化所有权；失败记录保留在 `controls-lifecycle-before`，修复后四组检查见 `controls-verified/results.json`。传感器数学、方向与模拟读数检查通过不代表已验证手机手感。

## Terraria Boss

沿用前轮视频、B 站及本机原版规则复核，数值和条件以本机 Terraria 1.4.5.8 的对应 Classic 分支为准。参照 EXE SHA-256：`960a03bff6050cf7be16dfc1a7b19e10fc2c4f8f835a6a3b135a50dd9e6ba2f3`，未修改原游戏。

本轮补上仆从 8 像素取整索敌、零差值和无目标运动；世吞转换时重置默认状态、按比例整数恢复血量并立即索敌，以及水域钻行；闲置骷髅手随头部撤退的 10 AI 帧倒计时。此前已修正的曼哈顿索敌、骷髅王旋转方向、独立退场时钟和世吞地形后绘制一并复验。

新增原版命中、死亡、吼叫、钻地六种声音，原版变身与死亡碎片素材和数量；碎片、血尘使用独立视觉随机流。原版像素素材仅有显示调色；生产模拟图集未替换。提取工具为 `tools/terraria_extract_effects.mjs`、`tools/terraria_extract_gore.mjs`，资源 SHA 记录在 `extract/assets/terraria/*-sources.json`。

`boss-verified/results.json` 的 31 项检查覆盖普通/2v2 禁止作弊和 Boss、13 空卡槽与局内改卡、经济血量清理、通用防御、原版血防/体节/手、1400/1399 变身阈值、100+100 AI 帧变身、每阶段三次冲刺、仆从存活、世吞头尾与多断点/孤节/全清、液体、手部六状态、800/400 AI 帧悬停旋转、白天行为、伤害缩放、魅惑甜薯免疫、普通攻击与冰冻，以及实际 UI 与导出读取回放验证。`eye-transform.png` 是实际运行时的变身和碎片画面；镜头再次调整后，该采样帧的眼球与变身碎片位于操作栏下方，未改 AI 轨迹。允许其他阶段短暂出屏。

适配边界仍明确保留：PvZ 没有 Terraria 腐化生态、装备仇恨、物品掉落或进度系统；测试场视为有效召唤区域。PvZ 独有的冰冻、黄油、眩晕沿用本游戏状态。Boss 不受击退，仆从可通过 PvZ 击退接口受力。血尘外观和碎片地形碰撞是轻量适配，并非原版 Dust/Collision 的逐像素复刻。测试镜头扩大天空视野，允许原版运动造成短暂出屏，不钳制 Boss 位置。不能把这些适配描述成整个 Terraria 游戏环境的完整复制。

## 验证与交付边界

最终机器可读索引为同目录 `work.json`，包含最新通过目录、编译结果和哈希。历史失败目录保留。所有运行测试使用证据目录内独立 userdata，未覆盖用户存档。

- Windows Release 编译通过；Boss 31 项、触控/传感器/显示上限/声音镜头 4 组、爆炸 8+1 场景通过。
- 既有材质隔离像素 88 项、昼夜/雨天/合作/2v2 阳光 25 项、原自爆功能 7 项回归通过。
- Android ARM64 最终候选 `pvp744-controls-boss-20261117-r3` 编译通过，构建前后源文件指纹一致，五个 `.so` SHA 校验通过。`libmain.so` SHA-256：`f42b1d3de6a57fa49832ab7c91c7072472d6ca785bbc5fc83a90c96f52e1e72c`。这是编译验证候选，不是安装包或实机通过证明。
- 首次 Android 尝试使用已不存在的旧 SDL 分发路径失败；改用现存冻结依赖 `dependencies/sdl2285` 后通过，未重新下载或改写参照目录。

手机未连接，本轮没有实机操作、GPU 驱动、低内存压力、陀螺仪手感或双机联网验收。没有正式出包，原启动入口保持正式交付构建。
