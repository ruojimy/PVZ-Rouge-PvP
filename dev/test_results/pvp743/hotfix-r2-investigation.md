# PvP74.3 r2 修复说明

本次修复性能记录按钮闪退和合作房主的主要异常内存增长；保持战斗数值与规则、材质别名、状态滤镜及命中逻辑。

## 实际原因与改动

1. 按钮在输入处理中创建记录器，绘制发生在其首次begin之前，CPU起点尚未初始化，真实SDL点击复现num - absent。记录器现仅计入由begin开启的完整帧，停止/替换后不再写入结束帧。
2. 记录器保存的绑定GC回调会反向持有自身。现只在绑定战斗时创建回调，解绑时移除并清空。弱引用测试证实模式切换/停止/重启后旧对象销毁。
3. 生产生成层遗漏剥离ContentZombie64Probe::alias_art中的aliases64观察数组，每个特殊僵尸每个原生tick持续追加。现使用精确路径、方法签名和原函数体SHA约束，仅去掉观察记录。实际canvas.alias、独立参考探针、贴图与规则均保留。

本次首个捕获异常为记录器的未初始化数值相减；没有把其他invalid map key报错一概归为同因，也没有修改全局字典/数值异常语义或吞掉战斗异常。
