# 自爆秘籍生产审计

实际生产 `Session.command(detonate)` 与生成UI链路共7项通过；结果为 `self-destruct-audit-r2/result.json`。本轮没有修改自爆伤害或触发机制，未能在这些场景复现“无伤害”，不能据此否定用户当局遇到的现象。

当前图鉴及原全量回归均规定主动点击己方存活僵尸触发，不是自然死亡自动爆炸。半径2.4格；植物和敌方戴夫伤害为 ceil(自爆时当前本体HP/25)，敌对/魅惑僵尸10倍。小丑保留原生爆炸分支，不使用普通自爆的数值分支。

- 当前HP为1/25/25.1/50/51/76/500时，实际植物扣血分别为1/1/2/2/3/4/20，源僵尸死亡且不能重复引爆。
- 76HP来源同时命中植物4、植物戴夫4、魅惑僵尸40；友方僵尸、僵尸戴夫、范围外植物均为0。
- 115.1px命中、115.3px不命中，周期战场接缝命中。
- 无秘籍、魅惑来源、墓碑及队友单位正确拒绝。双打用第二席位实际部署墓碑和普通僵尸，第一席位不能引爆，第二席位可以。
- 真实 `Application.detonate_target_at` 能选中来自Session快照的普通移动僵尸；真实 `Application.input` 发出的实际网络包交给Session后植物扣4。
- 普通死亡不触发该主动秘籍；小丑仍经-299原生路径爆炸并伤害英雄。
