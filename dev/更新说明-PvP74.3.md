# PvP74.3 更新说明

版本：1.6.0.74.3-typed.20261114。Android versionCode：1114081。

## 本次代码调整

- 材质工坊为暴怒补齐实际使用的蓝火炬1/2/3和树桩原图关联，卡牌原图保持独立；不改战斗图集、粒子采样或碰撞体积。
- 修正资源打开失败时的状态事务：新资源画布构造成功后再提交选择，避免资源名和旧画布错配；保留同资源重新打开时尚未保存的图层。按用户要求，本次未追加故障注入运行验证，不把源码审计和编译校验写成现场复现。
- 修复合作模式在场僵尸上限未传入生产生成预算：房间设置2或120分别按2或120生效，不再固定使用40。保留原Director优先级、整数转换和1–200约束；普通对战继续不受该上限限制。

完整39项状态见 [任务总清单](PvP74.3_任务总清单.md)，不因本次只汇报几个新反馈而删除旧任务。

停止新增实测指示之前，正常部署／魅惑／合作出生的传送带、客机wire地形接收与绘制，以及多种密度／站位下的高台堆叠已有追加证据；未复现新生产失效，没有擅自改变架设或跳跃规则。当前PC默认暴怒卡面与画布也未复现纯色块，不把4个资源关联补齐等同于已定位所有现场绿块原因。
