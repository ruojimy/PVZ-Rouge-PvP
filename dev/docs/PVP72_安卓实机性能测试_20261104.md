# PVP72 安卓实机性能测试（2026-11-04）

本次同机样本中，PVP72 的显示帧率比原生71提高约29%–36%，模拟速度变化较小。收益主要体现在绘制和缩放；混合与弹幕场景仍未恢复正常模拟速度。

测试设备为 vivo V2456A／SM7635／Android 16，实际4KiB内存页。两版均为2174×981逻辑/战场画布、2392×1080物理画布，原画、像素滤镜、optimized=true、seed301。每场景预热5秒、采样30秒，各3次独立进程，取中位数。

模拟倍率1.00×代表每现实秒推进250 native ticks。0.59×约为正常速度的六成，0.23×约为正常速度的四分之一；不能把FPS上涨解释为模拟内核同比加速。

## 采样边界

- 两版按旧版整组→覆盖升级→新版整组测量，没有交替安装；组内轮换场景顺序。旧版电池温度31.6–32.4℃，新版34.3–34.7℃。未固定系统调度、频率或清空其他应用后台，因此这些百分比只描述本次样本。
- 这是原生71→原生72版本对比，包含规则/入口差异；两边像素数量一致，未降低画质。场景不补充死亡单位，原始报告保存实际存活数量和模拟进度。
- 原生71使用已安装的诊断入口，五个游戏/SDL库逐字节等于原发布；资源来自当时仍安装的71正式包。PVP72使用签名正式APK入口，正式计时关闭额外计数。
- 部分运行时platform文本仍为Windows-10占位；本文设备信息以本轮ADB读取为准。没有测4 AI、真人联机/输入延迟或长局热稳态。
- 共18个正式样本全部完成。额外绘制计数补测前无线调试断开，补测0个完成，不计作通过。
