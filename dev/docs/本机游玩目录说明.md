# 本机游玩与项目目录

项目根目录为 `C:\Users\xiech\Downloads\PVZ_rougePvP_native`。

- 根目录的 `启动PvP.cmd`：打开独立本机游玩副本。
- `PVZ_rougePvP_native/`：完整可玩文件，仿照Python版的内层游戏目录。
- `PVZ_rougePvP_native/pvp_userdata/`：本机独立存档，已继承已有native存档。
- `dist/`：仅保留最新PvP72的Windows ZIP、安卓APK、源码检查点及其校验和、发布清单；当前为R8。

双击根目录或内层的启动脚本游玩；直接启动EXE仍使用AppData默认存档。
后续刷新可用嵌入式Python执行 `tools/setup_local_play.py`，直接读取交付ZIP，已有本机存档和relay配置不会覆盖。
按要求不另建旧目录备份；dist仅保留最新交付文件，AppData存档原位保留。

旧路径 `PVZ-PvP71-Native` 仅为指向新项目的目录链接，兼容当前Codex工具进程；没有另一份项目数据。
