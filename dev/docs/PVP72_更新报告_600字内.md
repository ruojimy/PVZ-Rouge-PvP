# PvP72 更新报告

PvP72调整原始土豆地雷18血、萝卜伞100阳光36血、双子向日葵90阳光、火爆辣椒750伤害（英雄16），并更新橄榄球、毁灭菇及辣椒僵尸等费用和冷却。移速增益改为加算，修正飞鸟拦截、魅惑索敌、根部保护、模仿费用与2v2共用出兵点；植物AI每8秒补贴25阳光，改进阵容推荐和存取。

性能方面加入SSE2/NEON透明混合、复用缩放目标、C++目标查询及有界日志。此次修复安卓玉米卷图标哈希退化造成的选卡卡死、前后台事件遗漏、USB初始化异常和文件同步空实现。历史Windows局部微基准中，透明绘制与缩放耗时约降78%/87%，目标查询场景分配次数降8.3%；这些不等于整局FPS或手机收益。

本轮虚拟机战斗单次PSS约630MiB、RSS729MiB，含ARM转译，不能视为手机峰值或内存降幅。

R8已在虚拟机实测选卡到战斗、两方部署、铲除、暂停恢复、前后台、结算与回放导出。198项触屏矩阵、669项关联检查、13组文件回放测试通过；有效旧档覆盖升级及新档同步冷启动后哈希一致。本机独立存档、原应用签名及完整失败证据保留。参考阵容花盆预留仍有改进空间，新版手机FPS与峰值内存待实机复测。
