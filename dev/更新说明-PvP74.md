# PvP74 · 材质工坊

构建：`1.6.0.74-typed.20261113`。

主界面新增“材质工坊”，与地图编辑器并列。支持 232 张卡牌及 4188 项绘画资源，包括植物、僵尸、弹幕、分层部件、动画帧、状态变体、完整卡面图标和场景界面资源。选择卡牌直接打开本体画布，“相关部件”可切换该卡的其他贴图；弹幕与全部资源也可直接搜索。

画布按原资源尺寸建立，支持载入原图、透明清空、PNG/JPEG/BMP 图片导入，提供等比居中、拉伸和原尺寸裁切三种适配方式。提供铅笔、橡皮、填充、取色、直线、空心/实心矩形和椭圆、选区移动、复制剪切粘贴、翻转旋转、缩放平移、像素网格、RGBA 调色、8 个图层及撤销重做。图片可单独导出透明 PNG，整个材质包可导出为可继续编辑的 `.pvptex` 文件。

点击“保存启用”应用材质。返回资源库、离开工坊、切到后台或正常关闭时会保存编辑内容。“原版材质”关闭替换并保留已绘制的包。没有单独绘制的黑白、受伤、冰冻、灰烬与魅惑变体，会沿用新造型生成对应状态。

联机中以房主材质为准，自动分片共享给客机和观众；带进度显示、SHA-256 摘要核对、尺寸与 PNG 内容检查及本地缓存。客机不能反向修改房主材质。共享内容仅在当前连接使用，退出后恢复客机自己的材质，原有文件保留。材质替换只进入显示链，战斗碰撞、粒子采样、随机数和回放校验使用原始资源。

材质文件在当前用户数据目录下的 `texture-packs/`，不会写回安装目录里的原图。单包上限 32 MB、8 个图层，撤销历史最多 40 步且有 64 MB 内存上限。联机玩家和观众均需升级到同一 PvP74 构建；旧回放使用录制时的版本播放。

PC 和 Android 共用同一材质格式。Windows 提供原生文件选择窗口及图片拖入；Android 使用系统文件选择与“另存到”界面。构建、签名核对与桌面自动化检查不等同于安卓真机操作验收。
