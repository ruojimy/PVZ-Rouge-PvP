植物大战僵尸 · 横版对战（PvP71 纯 C++ 版）

启动：双击 PvZPvPNative.exe（无需安装 Python）。

内容：
- 本地演练（双键盘对战）、创建/加入房间（局域网直连 TCP，默认端口见房间界面）、
  公开大厅（云端中继，地址在 relay.json）、2v2、观战、对局回放、地图编辑器、教学关卡。
- 合作闯关：主页底部「合作闯关」，或公开大厅里的「[合作] 一起闯关来个搭档」。
- 大厅固定 AI 房间：公开大厅前几行（内置 r22 AI 对手 / 队友）。

注意：
- 本版与 Python 版 PvP71 不互通（只能与同为 C++ 版的玩家联机）。
- 存档与设置保存在 %APPDATA%\PVZ-PvP-Native，不会影响 Python 正式版存档。
- 请保持文件夹结构完整（extract、图片、音乐、音效、relay.json 需与 EXE 同目录）。
- 若程序异常退出，会在本目录写入 crash-native.txt，请附上反馈。
