# PVZ-Rouge · 对战模式（PvP）

《植物大战僵尸》Roguelike 改版的**对战模式（PvP）**发布记录与开发包。

## 下载

到 [Releases](../../releases) 取对应版本：

| 版本 | 构建 | 内容 |
| --- | --- | --- |
| [v1.5.0.1-pvp44](../../releases/tag/v1.5.0.1-pvp44) | `1.5.0.1-pvp.44` | 开发者包 |

- **开发者包** —— 含 modkit 源码、测试套件、验证记录与架构 / 运维文档，面向二次开发与自建联机中继服务。入口 `launch_pvp.cmd`。
- **发布包** —— 开箱即玩 + 联机，面向普通玩家。

> 包体超过 GitHub 单文件 100 MB 硬限，因此全部以 **Release 附件**形式分发，不放进仓库文件树。

## 校验

每个 Release 的说明里给出整包 SHA-256 与内置 EXE SHA-256；包内另有 `SHA256SUMS.txt` 做逐文件校验。下载后请自行比对再使用。

## 说明

- 原版模式仍由游戏原引擎处理，对战使用独立规则。
- 分发包不含个人存档与联机凭据。
- 附件名统一使用英文，因为 GitHub 会剥离附件名中的非 ASCII 字符；包内目录名与文档保持中文原名。
